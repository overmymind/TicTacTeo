# Руководство пользователя: Игра «Крестики-Нолики»

Добро пожаловать в классическую игру «Крестики-Нолики», реализованную в виде приложения Windows Forms!

# 🎮 Инструкция для игрока

# Цель игры

Опередить соперника и выстроить линию из трех своих символов (горизонтально, вертикально или по диагонали).

# Как играть:

1. Начало игры: При запуске приложения перед вами откроется игровое поле из 9 пустых квадратных кнопок. Первым всегда ходит игрок, играющий за «Х» (Крестики).

2. Игровой процесс:
 • Текущий ход отображается внизу экрана в поле «Ход: ...».
 • Нажмите на любую пустую клетку на поле, чтобы поставить туда свой символ.
 • После клика кнопка становится неактивной, и ход автоматически переходит к следующему игроку (на «О»).

# Объяснение работы кода (для разработчика)

Логика игры написана на языке C# для платформы Windows Forms. Ниже разобраны основные технические моменты и алгоритмы.

# 1. Глобальные переменные (Хранение состояния)

Для отслеживания игрового процесса используются три ключевые переменные:                                                                                       
• string current_player; — хранит строку "X" или "O", показывая, кто ходит в данный момент.                                                                   
• int turn_count; — счетчик ходов (от 0 до 9). Помогает определить, когда наступила ничья.                                                                     
• Button[,] buttons; — двумерный массив размером 3х3. Он связывает визуальные кнопки на форме с координатной сеткой в коде, чтобы их было удобно проверять в циклах.

# 2. Алгоритм проверки победителя

Чтобы понять, выиграл ли игрок, программа после каждого клика вызывает метод CheckForWinner(), объединяющий три проверки:                               
• Проверка строк (CheckRows): Цикл for поочередно проверяет каждую из 3-х строк. Если во всех трех ячейках одной строки (например, [i, 0], [i, 1] и [i, 2]) текст совпадает с символом текущего игрока, метод возвращает true.                                                                                      
• Проверка столбцов (CheckColumns): Работает аналогично строкам, но фиксирует индекс столбца и перебирает строки: [0, i], [1, i] и [2, i].                   
• Проверка диагоналей (CheckDiagonals): Вручную проверяет две главные диагонали поля: от верхнего левого угла к правому нижнему ([0,0], [1,1], [2,2]) и от верхнего правого к левому нижнему ([0,2], [1,1], [2,0]).                     

# 3. Обработка клика по кнопке (Button_Click)

Вместо написания отдельного кода для каждой из 9 кнопок используется один общий обработчик событий.                                                   
• С помощью конструкции (Button)sender программа понимает, на какую именно из 9 кнопок нажал пользователь.                                             
• Кнопке присваивается текст текущего игрока ("X" или "O"), и она деактивируется (Enabled = false), чтобы нельзя было сходить в нее дважды.                 
• Происходит переключение хода с помощью тернарного оператора: current_player = (current_player == "X") ? "O" : "X";.                                 

# 4. Сброс игры (ResetGame)

При нажатии кнопки «начать заново» (или при старте программы) вызывается метод ResetGame(), который:                                                
1. Сбрасывает счетчик ходов на 0 и возвращает ход игроку "X".                                                                         
2. Заново инициализирует массив кнопок buttons.                                                                          
3. Через цикл foreach пробегает по всем кнопкам, очищает их текст, делает их активными и заново привязывает к ним событие клика.
